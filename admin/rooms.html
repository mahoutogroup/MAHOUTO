🗓️ Forfaits d'abonnement

Les forfaits proposés dans les salons passés en « mode abonnement ». Les prix se changent ici, sans redéployer. Un forfait inactif n'est jamais proposé. Les paiements se cumulent : chaque paiement ajoute ses jours à l'abonnement du membre.

⚠️ Le forfait de test « test-1-jour » est ACTIF : désactive-le après ton essai, avant d'activer le mode abonnement sur un vrai salon.
